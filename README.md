# sql-practice-real-scenarios

This repository contains 100+ SQL tasks based on real-world business scenarios.
It is designed to strengthen practical SQL skills commonly used in backend
development, reporting, and data analysis.

## Topics Covered
- Table design and relationships
- JOINs (INNER, LEFT)
- GROUP BY and HAVING
- Subqueries
- EXISTS / NOT EXISTS
- Aggregations
- User-defined functions
- Stored procedures
- Views

## Database
- SQL Server

## Structure
All tasks are stored in a single SQL file and clearly separated by numbered
sections and comments for readability.
